# Wave Survival Mod

Мод для Minecraft **1.20.1 (Forge 47.x, Java 17)**: игрок обороняется на арене от волн врагов. С каждой волной враги сильнее, каждые 5 волн появляется босс. За убийства даются очки, которые тратятся на прокачку оружия и баффы.

## Возможности

- Волны врагов с автоматическим масштабированием: здоровье, урон, скорость, броня (через `AttributeModifier`)
- Босс каждые 5 волн: больше HP, свой босс-бар, увеличенный размер, экипировка
- 8 случайных скинов для врагов (`skin_1.png` … `skin_8.png`)
- Случайное имя над головой каждого врага (`CustomName`, видно всегда)
- Экономика: очки за убийства и за прохождение волны
- Магазин на клавише **B**: урон, отбрасывание, скорость атаки, баффы, лечение
- Команды для разметки арены

## Где менять ники мобов

Файл: `src/main/java/com/example/wavesurvival/entity/WaveMobEntity.java`

В начале класса находятся два массива:

```java
private static final String[] NAMES = {
        "Бродяга", "Громила", "Тень", "Клык", "Мясник", "Ржавый",
        "Шрам", "Волк", "Гвоздь", "Костолом", "Хромой", "Упырь"
};
private static final String[] BOSS_NAMES = {
        "Король Арены", "Железный Барон", "Палач", "Повелитель Волн"
};
```

- `NAMES` — имена обычных врагов. Одно выбирается случайно при спавне.
- `BOSS_NAMES` — имена боссов (в игре отображаются как `☠ Имя ☠`).
- Менять можно любое количество строк: добавляйте, удаляйте, редактируйте. Главное, чтобы каждая строка была в кавычках и через запятую, последняя без запятой.
- После правки пересоберите мод: `./gradlew build`.

Выбор имени происходит в методе `applyWave(...)` той же файла, строка с `setCustomName(...)`.

## Скины

Положите 8 PNG (64x64) в `src/main/resources/assets/wavesurvival/textures/entity/` и назовите строго:

```
skin_1.png  skin_2.png  ...  skin_8.png
```

Без пробелов, скобок и заглавных букв. Иначе Minecraft не загрузит текстуру.

## Сборка

```bash
./gradlew build
```

Готовый `.jar` появится в `build/libs/`. Положите его в папку `mods` клиента и сервера.

## Настройка арены

1. Создайте Superflat-мир в Creative.
2. Выполните: `/gamerule doMobSpawning false`, `/gamerule doDaylightCycle false`, `/time set day`.
3. Постройте площадку примерно 40x40 со стенами 6–8 блоков, сверху Barrier-блоки.
4. Встаньте в каждую точку появления врагов и выполните `/wave addspawn`.
5. Встаньте в центр арены и выполните `/wave setplayer`.
6. Запуск: `/wave start`. Остановка: `/wave stop`.

## Команды (нужен уровень доступа 2)

| Команда | Действие |
|---|---|
| `/wave start` | Запустить режим волн |
| `/wave stop` | Остановить и убрать всех врагов |
| `/wave addspawn` | Добавить точку спавна на вашей позиции |
| `/wave clearspawns` | Удалить все точки спавна |
| `/wave setplayer` | Задать точку появления игрока |

## Баланс (где что крутить)

| Что | Где |
|---|---|
| Рост HP/урона/скорости/брони по волнам | `WaveMobEntity.applyWave()` |
| Количество врагов, пауза между волнами, лимит одновременно живых, частота боссов | константы в `WaveManager.java` |
| Награда за убийство | `Economy.onKill()` |
| Цены и максимальный уровень улучшений | `Economy.upgradeCost()`, `MAX_LEVEL` |
